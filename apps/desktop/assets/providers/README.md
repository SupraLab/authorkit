# Provider logos

SVGs from [lobe-icons](https://github.com/lobehub/lobe-icons) (MIT, Copyright (c) 2023 LobeHub).
PNGs are 128×128 rasterizations of those SVGs for egui textures.

Presets: `openai`, `anthropic`, `gemini`, `mistral`, `deepseek`, `xai`, `openrouter`, `groq`, `ollama`.

Used only to identify LLM providers in the settings / onboarding pickers.
