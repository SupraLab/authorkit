# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-27

## Context

AuthorKit is going open source. Contributors (human and AI assistants) need to know why the
codebase looks the way it does before changing foundational choices.

## Decision

We will record architecture decisions as ADRs in `docs/adr/`, using Michael Nygard's format, one
Markdown file per decision, numbered sequentially.

## Consequences

Decisions become reviewable in PRs and discoverable. Changing a recorded decision requires a new
superseding ADR, which adds a small amount of process.
